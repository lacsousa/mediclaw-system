# MediClaw — Identidade Visual (proposta v1)

Identidade própria do MediClaw, sem vínculo com marcas de terceiros.

## Paleta

| Papel | Cor | Hex |
|---|---|---|
| Primária (confiança clínica) | Teal profundo | `#0F766E` |
| Primária escura | Teal noite | `#134E4A` |
| Acento (energia/CTA) | Âmbar | `#D97706` |
| Fundo claro | Off-white | `#FAFAF7` |
| Fundo suave | Verde-gelo | `#ECF5F3` |
| Texto | Grafite | `#1C2B2A` |
| Texto secundário | Cinza-esverdeado | `#5B6B69` |

## Tipografia

- **Títulos:** Fraunces (serif — autoridade e cuidado) · fallback Georgia
- **Corpo/UI:** Inter · fallback system-ui

## Tom de voz

Sóbrio, técnico e transparente. Fala com o profissional de saúde de igual para igual: sempre "apoio à decisão", nunca "diagnóstico automático". Limitações e guardrails são apresentados como diferencial, não escondidos.

## Uso

A landing page em `marketing/landing/index.html` implementa esta identidade e serve de referência para materiais futuros (deck, posts, one-pager).
